# 删除弹窗调整

按用户直接要求移除永久删除的 DELETE 输入，保留预览、明确的永久删除选项、一次风险勾选和最终删除按钮。API 保留会话 ID、计划 nonce、时效和目标核验，不再要求文字确认。

根弹窗使用纵向 flex；内容区单独滚动；风险勾选、取消及删除按钮固定在底部。永久删除状态显示不可恢复提示。

正式数据目录只读统计有 91 个会话、约 97 MiB 解码日志，超出旧 32 MiB 全目录引用额度。将引用扫描额度调整为 256 MiB，保留事件数与独立文件事务额度，并给超限错误提供明确中文说明。

验证：先观察永久删除测试和真实 NEXT 布局回归失败，再修复；在隔离会话上验证正常和永久删除，以及 800/720/600 高度下失败预览的固定操作区。正式会话不自动删除，不新增备份或校验和。
