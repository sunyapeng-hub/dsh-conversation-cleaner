# 1.0.0-rc.7 — 2026-11-03

点击删除时自动关闭本宿主的空闲目标会话，等待原始 AgentHandle 完成日志刷盘和租约释放，再按原清单重新核验并删除。预览与取消不释放会话；不删除锁文件、不关闭其他会话。运行中、维护中、有队列或未发送附件、跨进程占用仍拒绝。释放后如预览失效，保留数据并重新发布会话行。

首次升级需正常重启宿主，使插件能够保留后续创建/恢复会话的关闭句柄。适配 Windows NEXT 2.0.20-next / Core 0.2.1-rc.3。历史会话的归属证明限制独立存在，不因自动关闭而跳过。

# 1.0.0-rc.6 — 2026-11-03

弹窗精简：主界面仅保留会话名、三档范围、一行说明、永久删除和取消/删除。元数据与清单默认折叠；恢复信息仅成功后按需展开。去掉风险勾选和重复警示，点击删除作为最终确认。失败才显示重试。后端鉴权、目标、计划及共享引用保护不变。

# 1.0.0-rc.5 — 2026-11-03

- 移除永久删除的 DELETE 文字确认，保留一次风险勾选与最终删除按钮。
- 内容单独滚动，风险勾选及取消/删除按钮固定底部；600/720/800 高窗口实测可见。
- 引用扫描额度从 32 MiB 提升至 256 MiB；单文件和隔离事务额度仍为 32 MiB；超限显示明确说明。
- 正式会话只读统计定位问题；不自动删除正式数据，不新增备份或校验和。

# 1.0.0-rc.4 — 2026-11-02

同一包在 Windows 官方 DSH Web 0.2.1-rc.3、NEXT 2.0.20-next / Core rc.3 完成三模式实际删除、重启无回潮与恢复。

B/C 已可执行：根级协作屏障、会话写租约、跨工作区引用核对、未发送上传保护、完整附件硬链接组、共享缓存索引事务，以及跨磁盘隔离恢复。

修复了旧 proof 误用、未知工具引用漏记、永久意图提前禁止恢复、死进程锁、丢失或被修改文件仍报恢复成功、恢复后身份变化、HTTP 提前结束释放锁、卸载 HMR 等待环、本地附件路径漏检、隔离旧事务依赖遗漏和损坏日志被宿主列表略过。

当前为候选版：未做其他平台、宿主版本和任意第三方插件组合验收；恢复无专用 UI；被宿主持有的目标须先关闭或切换。拒绝与保留条件会明确显示，不视为删除成功。
