# 1.0.0-rc.10 — 2026-11-04

本次修复六项审计缺陷，并提供完整的恢复与中断清理入口。

## 六项修复

1. **文件归属连续性**：路径被替换、产出被外部改写后撤销创建归属，后续 Agent 编辑不能重新把它认作本会话创建；正常连续 Agent 编辑仍保持归属。补齐真实原生 `edit` 工具没有 `operation` 字段时的参数适配。
2. **终态记录精简**：永久删除和恢复完成后剥离正文、恢复载荷、原路径等内容，只保留最小操作摘要。旧终态记录只通过用户明确点击「清理旧残留」处理，升级不会自动改写真实记录或删除已恢复的文件。
3. **零资源范围**：无归属产出、无附件时，只读取和绑定明确选中的目标会话。实际产出和附件清理仍保留全局引用屏障，不因精简范围而跳过共享检查。
4. **过期预览**：到期前自动刷新；提交前再次核对有效期，过期确认信息不发送到提交接口。范围变化清空旧预览，临时失败允许重试，关闭弹窗清理定时器及预览请求。
5. **恢复预检**：恢复前核对原工作区，缺失时在搬移文件前拒绝。用户可显式选择「恢复为未分组对话」，仅跳过缺失工作区，保留仍存在的成员关系及置顶、归档状态。恢复失败保留可重试状态，不显示虚假成功。
6. **永久清理续清**：永久清理中断后，可针对原操作继续清理剩余精确隔离文件。已完成的文件不重复要求存在，替代文件仍拒绝；普通可恢复删除不会因此转为永久删除。

## 使用变化

- 删除成功弹窗可直接点击「恢复」，成功后显示「已恢复」。
- 会话菜单增加小入口「删除记录与恢复」。本插件详情也提供同名入口，会话列表删空后仍可从 **插件 → 本包详情 → 删除记录与恢复** 进入；其他插件详情不显示该入口。
- 历史管理按用户选中的单条完整操作 ID 执行恢复、未分组恢复、继续永久清理或清理旧终态残留。列表使用标题、简短时间和本地化状态；完整操作 ID 收进折叠详情。
- 保留简洁主弹窗与固定底部按钮。点击操作按钮即为最终确认，不新增 DELETE 输入框或额外风险勾选。

## 验证与限制

rc.10 已在 Windows NEXT 2.0.20-next / Core 0.2.1-rc.3，以及官方 DSH Web 0.2.1-rc.3 完成 A/B/C 三种范围实际删除和重启恢复。新增故障注入与界面专项的最终覆盖以本次交付验收记录为准，不预先声明全部通过；自动测试总数也以最终记录为准。

继续使用宿主私有 API 和 Cordis 4.0.5 的精确适配，仅声明上述 Windows 宿主版本的结果。未知协调版本默认拒绝深度清理，未做 macOS/Linux 与任意第三方插件组合的完整验收。共享数据根要求所有写入宿主安装兼容插件。

正式用户数据只核对预览，未执行真实删除；删除、恢复及故障注入仅使用隔离测试数据。不使用系统回收站，不承诺擦除云端、备份或其他设备副本。

安装后正常重启宿主。恢复与中断处理步骤见 [RESTORE.md](RESTORE.md)，此前版本历史保留在 [RELEASE_NOTES.md](RELEASE_NOTES.md)。
