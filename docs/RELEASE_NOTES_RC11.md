# 1.0.0-rc.11 — 2026-11-04

修复历史会话因文件归属缺失而无法删除的问题。

- 选中 B/C 模式但资源清理依据不完整时，预览明确显示「本次仅删除对话，文件和附件保留」，仍可点击删除。选定模式保留，实际清单只列入该会话的日志；不会根据 Shell 输出补造文件归属。
- 保留策略适用于未知或损坏的归属记录、外部日志格式不支持/损坏、旧恢复记录缺少引用、附件引用证明不充分等资源问题。不会清理对应的工作区文件、附件或缓存。
- 保留策略写入预览/提交元数据，依据变化时需要重新预览，不能把预览承诺保留的文件临时扩大为删除项。
- 会话正在运行、外部所有权、索引冲突、目标日志损坏、事务和路径安全检查保持有效。
- 纯日志恢复不再解析旧归属证明，避免已删除会话因损坏的历史记录无法恢复。

Windows 既有精确宿主版本下，真实 NEXT 和 Web 分别验证历史归属不完整的 B 普通删除及恢复、C 永久删除；均核对工作区文件及附件原始字节保持不变，只删除新建的合成目标会话。自动测试和正常资源删除/重启恢复覆盖见验收报告。

无需额外确认框。升级采用 NEXT 应用内卸载、安装新版、启用并正常重启；隔离恢复记录保留。正式真实会话没有参与删除测试。私有 API、共享根参与者、Windows 和精确版本范围与 rc.10 相同。
